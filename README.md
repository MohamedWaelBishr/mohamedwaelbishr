## 👋 About

I build the screens where decisions get made.

Right now that means **real-time financial dashboards at Octane** — transaction monitoring, risk assessment, analytics that update while you watch. The kind of UI where a dropped frame or a mislabeled axis costs someone money. I care about both halves of that: the render path *and* the pixel.

Before Octane I was full-stack at **Everest Minds**, shipping process-automation tools and cross-platform apps for healthcare — React, NestJS, Angular, React Native, MySQL, MongoDB. Owned features end to end, design through deploy.

Before software, I worked in **biomedical and telecom** — field ops, complex hardware, compliance. That's where I learned that most bugs are systems problems wearing a code costume.

**What I'm into lately:** design systems that don't rot, motion that means something, render performance, and AI-assisted developer tooling — I write my own.
